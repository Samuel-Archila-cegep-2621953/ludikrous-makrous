# Modèles 3D

Pour créer tous les modèles 3d de ce projet incluant l'entrepôt, le menu principal, Markous, le missile, les pilliers, etc. nous avons utilisé le logiciel *Blender*.

Le modèle 3d de Markous a été celui qui a pris le plus de temps, car nous lui avont fait un modèle avec un squelete et des animation. Nous l'avons aussi placé dans le menu principal avec une animation.

Pour créer quelques textures, nous avons aussi utilisé le logiciel *Microsoft Paint*.

C'est tout ce que nous avons utilisé. *Blender* contient vraiment tout ce qui a été nécéssaire.

Nous avons ensuite envoyé ces modèles 3d dans le projet sous le format GLB ou FBX et utilisé ursina pour afficher ces modèles.

Pour le menu principal, nous avons créé une animation de 1 seconde répétée indéfiniment sous format mp4 avec *Blender*. Nous avons utilisé la technologie du ray-tracing dans blender pour bien simuler la lumière des lumières de la vidéo sur les murs et toute la scène.
